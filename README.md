# TradPlus InMobi Adapter Swift Package

Swift Package Manager support for the TradPlus InMobi adapter (15.18.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-InMobi.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-InMobi.git", exact: "15.18.0")
```

Third-party dependency: InMobi SDK `11.5.0`. Minimum iOS 12.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.18.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
